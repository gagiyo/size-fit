# 내 옷사이즈

쇼핑몰 사이즈표를 캡처로 올리거나 표를 붙여넣으면, 186cm·73kg 슬림한 체형 기준으로
어떤 사이즈가 맞는지 항목별로 비교해 주는 개인용 사이즈 가이드(PWA)입니다.

## 화면

- **사이즈표 분석** — 상의·아우터·정장셔츠·하의별 기준 범위와 비교해 최적/차선 사이즈를 고르고,
  어깨·가슴단면·총장·소매·허리·아웃심마다 `딱 맞음 / 약간 여유 / 짧음 주의 / 큼 / 타이트` 배지를 보여 줍니다.
  - 이미지 OCR(Tesseract.js `kor+eng`, 진행률 표시) → 편집 가능한 표
  - 텍스트·엑셀 표 붙여넣기(열/행 방향 자동 인식, 둘레→단면 환산, 반팔 소매 제외)
  - 1클릭 샘플 5종, 행 추가/삭제, 직접 수정
- **내 치수** — 키·몸무게·허리 인치·평소 상의와 12개 실측치를 저장(localStorage)하고,
  종류별 추천 사이즈와 쇼핑 전 확인 목록을 봅니다.
- **간편 피팅** — 내 사진 위에 옷 사진을 얹어 드래그·핀치·회전·투명도 조절 후 PNG로 저장합니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` `styles.css` `app.js` | 앱 본체 (프레임워크 없음) |
| `manifest.json` | PWA 설치 정보 (standalone) |
| `sw.js` | 오프라인 셸 (CDN 요청은 건드리지 않음) |
| `icon-180.png` `icon-192.png` `icon-512.png` | 앱 아이콘 (행거 + 줄자) |

## 쓰는 법

Safari에서 **공유 → 홈 화면에 추가**를 누르면 전체 화면 앱처럼 열립니다.
입력한 치수와 사이즈표는 그 기기의 브라우저 저장소에만 남습니다.

실제 착용처럼 옷이 몸의 굴곡을 따라 휘어지는 합성은 2D 도구로는 불가능해서,
그런 결과가 필요하면 두 사진을 Pickle 채팅으로 보내면 됩니다.
